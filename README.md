
# HVAC Enquiry Assistant

A beginner Python project that simulates a basic enquiry assistant for an HVAC service business.

## Objective

Practice Python fundamentals while building the foundation for a future AI-powered HVAC enquiry automation system.

## Features

- Displays sample HVAC business information
- Recognises basic service enquiries
- Shares service areas and opening hours
- Responds to simple AC repair questions
- Provides a fallback for unrecognised messages
- Runs interactively in the terminal

## Technologies

- Python
- VS Code
- Git and GitHub

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python main.py
```

## Current Limitations

This is a rule-based prototype. It does not use an AI model, connect to WhatsApp, store leads, or confirm appointments.
